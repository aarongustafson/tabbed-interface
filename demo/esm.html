Load the class and register the element

Importing the class does not register it. Register once to enhance the original sections. Without JavaScript, or if the module fails to load, all headings and content remain readable. If the tabs don’t fit on one row, the component also shows every section.

Tab into the selected tab and use arrow keys to move focus. Press Enter or Space to select it. Home and End move focus to the first and last tabs. 

<tabbed-interface>
  <h2>Opening hours</h2>
  <p>Tuesday through Sunday, 10am to 5pm.</p>
  <h2>Getting here</h2>
  <p>The museum is across from Central Station.</p>
  <h2>Contact</h2>
  <p>Ask at the front desk for help planning your visit.</p>
</tabbed-interface>

<script type="module">
  import { TabbedInterfaceElement } from
    'https://esm.sh/@aarongustafson/tabbed-interface@3.0.4/tabbed-interface.js?bundle&target=es2022';
  if (!customElements.get('tabbed-interface')) {
    customElements.define('tabbed-interface', TabbedInterfaceElement);
  }
</script>
