<tabbed-interface>

This component turns headings and their content into tabs when the tablist fits on one row. When it doesn’t fit, the component shows every section in reading order.

Turn related sections into tabs

Wrap headings and their content in <tabbed-interface>. The first direct-child heading’s level defines the sections. This page loads ../define.js to register the element. Without JavaScript, or if the module fails to load, these headings and paragraphs remain readable together.

Tab into the selected tab, then use arrow keys to move focus. Press Enter or Space to select the focused tab. Home and End move focus to the first and last tabs. If the selected section contains a link or control, Enter or Space also moves focus to its first matching focusable element; otherwise focus stays on the tab. 

<tabbed-interface>
  <h3>Opening hours</h3>
  <p>Tuesday through Sunday, 10am to 5pm.</p>

  <h3>Getting here</h3>
  <p>The museum is across from Central Station.</p>

  <h3>Contact</h3>
  <p>Ask at the front desk for help planning your visit.</p>
</tabbed-interface>

Use shorter tab labels

Set data-tab-short-name on a heading to change the visible tab label. The full heading supplies the tab’s accessible name through aria-label; it isn’t the visible tab label. This example explicitly adds show-headers to request visible full headings in the panels too.

Choose short labels that remain recognizable in the full headings, whether you’re translating them or matching your application’s vocabulary. See the label reference for heading visibility behavior. 

<tabbed-interface show-headers>
  <h3 data-tab-short-name="Hours">Hours and admission prices</h3>
  <p>Admission is free on the first Sunday of each month.</p>
  <h3 data-tab-short-name="Travel">Travel to the museum</h3>
  <p>The station and bus stops are a short walk away.</p>
  <h3 data-tab-short-name="Access">Access during your visit</h3>
  <p>A step-free entrance is on the east side.</p>
</tabbed-interface>

Link to a section

Give each heading a unique ID and link to it with a URL fragment. These links select the matching section after upgrade and reach the native headings without JavaScript. Clicking a tab does not change the URL. Links to example blocks, such as #link-to-sections, don’t change selection.

Show every section when labels don’t fit

Resize the window to see these longer labels switch from tabs to linear sections. Fit depends on rendered labels, fonts, spacing, and selected-tab styles—not a fixed viewport breakpoint. Labels can wrap inside their buttons as long as the complete tablist fits on one row.

Use presentation="tabs" only if you’ll handle tab overflow at every width yourself. It disables this automatic switch. The older fixed-tabs option is deprecated but remains supported for compatibility. Printing still shows all sections and original headings; the selected tab and screen layout return afterward.

Respond to selection in your application

Read the selected tab from an event

Listen for tabbed-interface:change on the element. Select another tab to update the output below. tabIndex starts at zero; tabId and tabpanelId identify the generated tab and panel. Use textContent to display the detail as text. 

const eventTabs = document.querySelector('#event-demo');
const eventOutput = document.querySelector('#event-output');
eventTabs.addEventListener('tabbed-interface:change', (event) => {
  const { tabIndex, tabId, tabpanelId } = event.detail;
  eventOutput.textContent =
    `Tab changed: index=${tabIndex}, tabId=${tabId}, tabpanelId=${tabpanelId}`;
});

Select a tab from another control

Use first(), previous(), next(), and last() to select and focus a tab. Previous and Next wrap at either end. You can also assign activeIndex to select without moving focus. In linear layout, the methods remember selection without hiding sections or moving focus. The extra controls appear only after the module loads. 

const programmaticTabs = document.querySelector('#programmatic-demo');
const controls = document.querySelector('#selection-controls');
const methods = {
  first: () => programmaticTabs.first(),
  previous: () => programmaticTabs.previous(),
  next: () => programmaticTabs.next(),
  last: () => programmaticTabs.last(),
};
controls.querySelectorAll('button').forEach((button) => {
  button.addEventListener('click', methods[button.dataset.action]);
});
controls.hidden = false;

Switch presentation without replacing content

Use presentation to choose automatic fitting, tabs, or all sections. The presentation CSS part makes the expanded view a responsive grid. The read-only layout property reports the actual view, including automatic fitting and print. Enter a delivery note and change the view: selection, entered text, and nested component state stay attached to the original nodes. The controls remain hidden if the component cannot load; the content remains available. 

<style>
  #presentation-controls {
    margin-block-end: 1rem;
  }
  .presentation-example[data-layout='linear']::part(presentation) {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(min(14rem, 100%), 1fr));
    gap: 1rem;
  }
</style>
<div id="presentation-controls" hidden>
  <label for="presentation-mode">View sections</label>
  <select id="presentation-mode">
    <option value="auto">Automatic</option>
    <option value="tabs">Tabs</option>
    <option value="linear">All sections</option>
  </select>
</div>
<tabbed-interface id="presentation-example" class="presentation-example">
  <h3>Order details</h3>
  <p>Two notebooks and a pencil.</p>
  <h3>Delivery</h3>
  <label>Delivery note <input name="delivery-note"></label>

<script>
  customElements.whenDefined('tabbed-interface').then(() => {
    const mode = document.getElementById('presentation-mode');
    const example = document.getElementById('presentation-example');
    document.getElementById('presentation-controls').hidden = false;
    mode.addEventListener('change', () => {
      example.presentation = mode.value;
    });
  });
</script>

Style the tab controls

Style authored content with ordinary CSS and generated controls with ::part(). The component keeps your original nodes, event listeners, live form values, and form ownership. See the styling reference for parts and custom properties.

Keep focus styles geometry-stable: don’t change padding, border widths, or font sizes when a tab receives focus. Keep selection and focus distinguishable, and pair backgrounds with readable foregrounds. Check your styles with keyboard use and your users’ color settings.

Give tabs rounded outlines

Apply class="pills" to the component and use these part rules. The selected tab reverses the foreground and background; the browser still supplies the keyboard focus outline. 

tabbed-interface.pills::part(tablist) {
  gap: 8px;
  margin: 0 0 1em 0;
}

tabbed-interface.pills::part(tab) {
  background-color: Canvas;
  background-color: color-mix(in srgb, CanvasText 8%, Canvas);
  color: CanvasText;
  border: 1px solid CanvasText;
  border-radius: 999px;
  padding: 0.5em 1.5em;
}

tabbed-interface.pills::part(tab):hover {
  background-color: Canvas;
  background-color: color-mix(in srgb, CanvasText 16%, Canvas);
  color: CanvasText;
}

tabbed-interface.pills::part(selected),
tabbed-interface.pills::part(selected):hover {
  background-color: CanvasText;
  color: Canvas;
  border-color: CanvasText;
}

tabbed-interface.pills::part(tabpanel) {
  background-color: Canvas;
  color: CanvasText;
  border: none;
}

Underline the selected tab
