Load the definition helper

Importing the helper registers the default element when supported. Calling it again is safe. Without JavaScript, or if the module fails to load, all headings and content remain readable. If the tabs don’t fit on one row, the component also shows every section.

Tab into the selected tab and use arrow keys to move focus. Press Enter or Space to select it. Home and End move focus to the first and last tabs. This example uses @latest; pin a release in your application when you need a repeatable import. 

<tabbed-interface>
  <h2>Opening hours</h2>
  <p>Tuesday through Sunday, 10am to 5pm.</p>
  <h2>Getting here</h2>
  <p>The museum is across from Central Station.</p>
  <h2>Contact</h2>
  <p>Ask at the front desk for help planning your visit.</p>
</tabbed-interface>

<script type="module">
  import { defineTabbedInterface } from
    'https://unpkg.com/@aarongustafson/tabbed-interface@latest/define.js?module';
  defineTabbedInterface();
</script>
